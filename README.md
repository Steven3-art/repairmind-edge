\# RepairMind Edge



\*\*Agentic vision for evidence-driven inspection and troubleshooting of electronic and edge devices.\*\*



RepairMind Edge is an experimental Agentic Vision system designed to inspect electronic hardware using computer vision, structured visual evidence, and iterative troubleshooting workflows.



The project is being developed for the OpenCV AI Competition 2026 powered by AWS.



\## Core idea



RepairMind Edge does not attempt to diagnose hardware failures from a single image without evidence.



Instead, it follows an iterative workflow:



```text

Observe

&#x20; ↓

Extract visual evidence

&#x20; ↓

Assess evidence

&#x20; ↓

Decide the next inspection step

&#x20; ↓

Request another observation or measurement

&#x20; ↓

Update the investigation
